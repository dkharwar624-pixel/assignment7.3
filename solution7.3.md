 I created a responsive product listing containing six product cards, each with an image, product name, price, and Add to Cart button. The product container uses display flex and flex-wrap wrap, which allows the cards to stay in a row on large screens and automatically wrap to the next line when the screen becomes smaller, making it fully responsive without media queries for the basic wrapping behavior. I added spacing between cards using gap 20px which is cleaner than using margins and ensures equal spacing both horizontally and vertically. For flex properties, I experimented with flex-basis 250px which sets the initial ideal width of each card, flex-grow 1 which allows cards to grow and fill extra available space in the row so there is no empty space, and flex-shrink 1 which allows cards to shrink when the container is smaller than total basis. I also demonstrated different grow values by giving one card flex-grow 2 which makes it grow double compared to others, and another card flex-grow 1.5 to show proportional growth, while max-width 320px prevents cards from becoming too large and min-width 200px prevents them from becoming too small. On desktop width, four cards appear in a row, on tablet three cards, and on mobile one card per row due to flex-wrap and flex-basis 100% in media query.
